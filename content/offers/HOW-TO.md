# Offers & Announcements posters

Every image in this folder appears automatically on the Home and Admissions pages.

- **Add a poster:** upload a JPG or PNG here.
- **Remove a poster:** delete the image file.
- **Order:** newest first by file name — start names with the date, e.g. `2026-11-01-early-registration.jpg`.
- **Description for screen readers:** taken from the file name, so use words: `2026-11-01-early-registration.jpg` → "Early registration".

Remember: the fees table must always show full fees — put discounts only on posters.
