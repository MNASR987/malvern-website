# Brand folder

Upload the school's logo and photos here. The website picks them up automatically.

| File name | What it does |
|---|---|
| `logo.svg` or `logo.png` | Main logo in the header (replaces the "M Malvern" wordmark) |
| `logo-white.svg` or `logo-white.png` | Logo for dark backgrounds (footer, menu) — optional |
| `hero.jpg` | Large photo on the home page (also used as the still image for slow connections) |
| `hero-video.mp4` | Short silent looping clip for the home page (10–20 s). Any size up to 25 MB — it is compressed to under 5 MB automatically |
| any other photo | Used where a content file names it, e.g. `photo: "principal.jpg"` |

Photo rules: no student names; never photos showing the faces of girls in Grades 6–12;
prefer images without identifiable students unless consent is confirmed.
